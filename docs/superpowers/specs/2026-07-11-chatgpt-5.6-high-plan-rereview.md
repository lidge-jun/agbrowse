## Verified Findings Applied

1. The Thinking XPath selected the first later matching checkbox, not the
   immediate next sibling. The plan now requires `following-sibling::*[1]`, an
   exact `menuitemcheckbox`/`Thinking` contract, one direct-child switch, and
   adversarial sibling/detachment tests.
2. Citation completion had no terminal degraded state for selector or
   normalization failure. The plan now separates `unavailable` from
   `pending|unknown`, keeps ambiguous response roots non-terminal, and records
   `citations: []` plus `citations-unavailable` after grace.
3. Sources-pane association and closing lacked observed causality. Task 5 now
   captures pane before/after identity and the close mechanism; Task 8 tests
   stale, duplicate, unchanged, and close-failure cases.
4. Task 5 required DOM citation behavior but only implemented pure
   normalization. DOM behavior moved to Task 8, and the fake Page/Locator
   helper is owned and committed by Task 6.
5. The recovery regex accepted arbitrary slugs despite only UUID evidence.
   The V1 guard now permits only captured `/search/<UUID>` paths.
6. Lifecycle ownership recognized only the `www` origin. The plan now groups
   `perplexity.ai` and `www.perplexity.ai` under one HTTPS provider pool.
7. Copy and response-root semantic assumptions exceeded live evidence. Copy
   uses an accessible-name locator, while committed-root selectors must be
   fixture-derived from current-turn answer/footer behavior.
8. CLI effort aliases and MCP requested-provider/session-vendor conflicts could
   be silently ignored. Both now fail before browser/session-page access.
9. The dedicated Perplexity eval and watcher path were absent from final gates
   and smoke. `test:eval-perplexity` joins `gate:all`; smoke now runs
   send -> watch -> resume -> reattach with self-contained shell blocks.

## Scope Decision

The review suggested capturing the Sources close contract rather than guessing
it. This revision does not claim a close selector or Escape behavior that was
not observed. It makes authenticated capture a prerequisite to implementation.

The completed-session artifact is immutable in V1. Citations that appear after
the two-second grace do not mutate a terminal session; this keeps CLI, MCP, and
disk round-trips deterministic.

## Result

All technically verified findings above were incorporated into the TDD plan,
design, and live-observation caveats. A new external review is still required
before changing the plan's implementation-approval status to `ACCEPT`.
